# Flight Ticket Price Estimation

## Synopsis
Estimate flight ticket prices using airline, source, destination, travel month, booking lead time, stops, and duration.

## Objectives
- Explore flight booking data.
- Analyze factors affecting ticket prices.
- Compare airlines and routes.
- Prepare the dataset.
- Train a regression model.
- Estimate flight ticket prices.

## Tools
Python, Pandas, Matplotlib, Scikit-learn

## Machine Learning
Linear Regression with numerical scaling and categorical one-hot encoding.

## Evaluation
MAE, RMSE, R² score, actual-vs-predicted comparison, a new-flight prediction, and regression-coefficient feature analysis.
